# Description
PowerNapp은 일정에 따라 PC를 종료하거나 다시 시작하거나 절전 모드로 전환하는 앱으로, Windows 11에 기본으로 들어 있는 앱처럼 보입니다. 크기는 약 160KB이고 종속성이 없으며, 닫으면 메모리를 전혀 사용하지 않습니다.

일정은 Windows 작업 스케줄러 작업으로 등록되므로 다시 시작한 후에도, 앱을 닫은 상태에서도 계속 동작합니다. 트레이 아이콘을 끄면 PowerNapp은 아무것도 실행 상태로 남기지 않습니다: 0MB. 트레이 아이콘을 켜면 약 0.1MB, 창을 열면 약 2.3MB를 사용합니다.

동작(시스템 종료, 다시 시작, 절전, 최대 절전 모드, 로그아웃, 잠금, 화면 끄기)과 실행 시점(매일 지정한 시간, 선택한 요일, 카운트다운 후, PC를 사용하지 않을 때)을 선택하세요. 절전과 최대 절전 모드에서는 타이머로 PC 절전을 해제할 수도 있습니다. 예를 들어 오후 11시에 절전 모드로 전환하고 오전 7시에 바로 쓸 수 있도록 준비할 수 있습니다.

동작 1분 전에는 작은 알림 카드가 카운트다운을 표시하며, 지금 실행하거나 10분 후 다시 알림하거나 중지할 수 있습니다.

PowerNapp은 Windows 설정 앱의 디자인(카드, 토글, 플라이아웃, 밝은 테마와 어두운 테마)을 따르며 풀 컬러 아이콘을 사용합니다. 키보드와 내레이터로 사용할 수 있고, 어떤 모니터와 DPI 설정에서도 선명하게 표시됩니다. 35개 언어를 지원하며 앱에서 언어를 선택할 수 있습니다.

PowerNapp은 무료 오픈 소스(GPL-3.0)입니다.

# Short description
일정에 따라 PC를 종료, 다시 시작 또는 절전 모드로 전환합니다. Windows 작업 스케줄러가 작업을 처리하므로 PowerNapp은 닫으면 0MB를 사용합니다. 타이머로 PC 절전을 해제할 수도 있습니다. Windows 설정처럼 보입니다.
