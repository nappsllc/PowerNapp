# Description
PowerNapp は、PC のシャットダウン、再起動、スリープをスケジュールどおりに実行するアプリです。見た目は Windows 11 に最初から入っているアプリのようです。サイズは約 200 KB で、依存関係はなく、閉じた後はメモリをまったく使いません。

スケジュールは Windows タスク スケジューラのタスクとして登録されるため、再起動後もアプリを閉じた状態でも動作し続けます。トレイ アイコンをオフにすれば、PowerNapp のプロセスは何も残りません (0 MB)。トレイ アイコンがオンのときは約 0.1 MB、ウィンドウを開いているときは約 2.3 MB です。

操作 (シャットダウン、再起動、スリープ、休止状態、サインアウト、ロック、画面の電源を切る) と実行するタイミング (毎日決まった時刻、選んだ曜日、カウントダウン後、PC がアイドル状態になったとき) を選ぶだけです。スリープと休止状態では、タイマーで PC をスリープ解除することもできます。たとえば午後 11 時にスリープし、午前 7 時には使える状態にできます。

操作の 1 分前には小さなリマインダー カードがカウントダウンを表示し、今すぐ実行、10 分スヌーズ、停止を選べます。

PowerNapp は Windows の設定アプリのデザイン (カード、トグル スイッチ、ポップアップ、ライト テーマとダーク テーマ) に合わせ、フルカラーのアイコンを使っています。キーボードとナレーターで操作でき、どのモニターや DPI 設定でもくっきり表示されます。35 の言語に対応し、アプリ内で言語を選べます。

PowerNapp は無料のオープンソース ソフトウェア (GPL-3.0) です。

# Short description
PC のシャットダウン、再起動、スリープをスケジュールどおりに実行。処理は Windows タスク スケジューラが行うため、閉じた PowerNapp のメモリ使用量は 0 MB。タイマーによるスリープ解除にも対応。見た目は Windows の設定そのものです。

シャットダウン、再起動、スリープ、休止状態、サインアウト、ロック、画面の電源を切る
毎日、毎週、カウントダウン、アイドル時のスケジュール

無料のオープンソース (GPL-3.0)
