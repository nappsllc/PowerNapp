# Description
PowerNapp 可依排程關機、重新啟動電腦或讓它睡眠，而且介面看起來就像 Windows 11 內建的應用程式。它只有約 160 KB，沒有任何相依元件，關閉後完全不佔用記憶體。

排程會儲存為 Windows 工作排程器的工作，因此即使重新開機或關閉應用程式也會照常執行。關閉系統匣圖示後，PowerNapp 不會留下任何執行中的程序：0 MB。開啟系統匣圖示時約佔用 0.1 MB，開啟視窗時約佔用 2.3 MB。

選擇一個動作 (關機、重新啟動、睡眠、休眠、登出、鎖定或關閉顯示器) 以及執行時間：每天的指定時間、每週的指定日期、倒數計時結束後，或電腦閒置一段時間後。對於睡眠和休眠，PowerNapp 還能定時喚醒電腦，例如晚上 11 點睡眠、早上 7 點準備就緒。

執行動作前一分鐘，會出現一張小提醒卡片倒數計時，你可以立即執行、延後 10 分鐘或停止。

PowerNapp 沿用 Windows 設定應用程式的外觀 (卡片、切換開關、飛出視窗、淺色和深色佈景主題)，並配有全彩圖示。它支援鍵盤和朗讀程式，在任何顯示器和 DPI 設定下都清晰銳利。它提供 35 種語言，應用程式內可切換語言。

PowerNapp 免費且開放原始碼 (GPL-3.0)。

# Short description
依排程關機、重新啟動電腦或讓它睡眠。由 Windows 工作排程器執行工作，因此 PowerNapp 關閉後佔用 0 MB。還能定時喚醒電腦。外觀與 Windows 設定一致。
