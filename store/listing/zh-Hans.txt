# Description
PowerNapp 可按计划关机、重启电脑或使其睡眠，而且界面看起来就像 Windows 11 自带的应用。它只有约 160 KB，没有任何依赖项，关闭后完全不占用内存。

计划以 Windows 任务计划程序任务的形式保存，因此即使重启电脑或关闭应用也会照常运行。关闭托盘图标后，PowerNapp 不会留下任何正在运行的进程：0 MB。开启托盘图标时约占用 0.1 MB，打开窗口时约占用 2.3 MB。

选择一个操作 (关机、重启、睡眠、休眠、注销、锁定或关闭显示器) 以及执行时间：每天的指定时间、每周的指定日期、倒计时结束后，或电脑空闲一段时间后。对于睡眠和休眠，PowerNapp 还可以定时唤醒电脑，例如晚上 11 点睡眠、早上 7 点准备就绪。

执行操作前一分钟，会弹出一个小提醒卡片进行倒计时，你可以立即执行、推迟 10 分钟或停止。

PowerNapp 沿用 Windows 设置应用的外观 (卡片、开关、浮出菜单、浅色和深色主题)，并配有全彩图标。它支持键盘和讲述人，在任何显示器和 DPI 设置下都清晰锐利。它提供 35 种语言，应用内可切换语言。

PowerNapp 免费且开源 (GPL-3.0)。

# Short description
按计划关机、重启电脑或使其睡眠。由 Windows 任务计划程序执行任务，因此 PowerNapp 关闭后占用 0 MB。还可以定时唤醒电脑。外观与 Windows 设置一致。

# Features
关机、重启、睡眠、休眠、注销、锁定或关闭显示器
每天、每周、倒计时或空闲计划
定时将电脑从睡眠或休眠中唤醒
关闭后占用 0 MB：由 Windows 任务计划程序执行任务，重启后依然有效

35 种语言，应用内可切换语言
免费且开源 (GPL-3.0)
