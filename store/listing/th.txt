# Description
PowerNapp ปิดเครื่อง เริ่มระบบใหม่ หรือสั่งให้พีซีของคุณเข้าสู่โหมดสลีปตามกำหนดการ ในแอปที่ดูเหมือนมาพร้อมกับ Windows 11 มีขนาดประมาณ 200 KB ไม่ต้องติดตั้งอะไรเพิ่ม และเมื่อปิดแอปแล้วจะไม่ใช้หน่วยความจำเลย

กำหนดการคืองานในตัวจัดกำหนดการงานของ Windows จึงยังทำงานต่อได้แม้หลังเริ่มระบบใหม่และแม้ปิดแอปแล้ว เมื่อปิดไอคอนในถาด จะไม่มีส่วนใดของ PowerNapp ทำงานอยู่เลย: 0 MB เมื่อเปิดไอคอนในถาดจะใช้ประมาณ 0.1 MB และเมื่อเปิดหน้าต่างไว้ประมาณ 2.3 MB

เลือกการดำเนินการ (ปิดเครื่อง เริ่มระบบใหม่ สลีป ไฮเบอร์เนต ลงชื่อออก ล็อก หรือปิดจอแสดงผล) และเวลาที่ต้องการ: ในเวลาที่กำหนดทุกวัน ในวันที่เลือกของสัปดาห์ หลังจากนับถอยหลัง หรือเมื่อพีซีไม่ได้ใช้งาน สำหรับสลีปและไฮเบอร์เนต PowerNapp ยังปลุกพีซีด้วยตัวจับเวลาได้ด้วย เช่น สลีปตอน 23:00 แล้วพร้อมใช้งานตอน 07:00

หนึ่งนาทีก่อนการดำเนินการ การ์ดแจ้งเตือนเล็กๆ จะนับถอยหลังและให้คุณสั่งทำงานทันที เลื่อนออกไป 10 นาที หรือหยุด

PowerNapp มีหน้าตาเหมือนแอปการตั้งค่าของ Windows (การ์ด สวิตช์ เมนูแบบลอย ธีมสว่างและมืด) พร้อมไอคอนสีเต็ม ใช้งานได้กับคีย์บอร์ดและผู้บรรยาย และคมชัดบนทุกจอภาพและทุกการตั้งค่า DPI มีให้ใช้ 35 ภาษา พร้อมตัวเลือกภาษาในแอป

PowerNapp ใช้งานได้ฟรีและเป็นโอเพนซอร์ส (GPL-3.0)

# Short description
ปิดเครื่อง เริ่มระบบใหม่ หรือสลีปพีซีตามกำหนดการ ตัวจัดกำหนดการงานของ Windows เป็นผู้ทำงาน PowerNapp จึงใช้ 0 MB เมื่อปิดแอป และยังปลุกพีซีด้วยตัวจับเวลาได้ หน้าตาเหมือนการตั้งค่าของ Windows

# Features
ปิดเครื่อง เริ่มระบบใหม่ สลีป ไฮเบอร์เนต ลงชื่อออก ล็อก หรือปิดจอแสดงผล
กำหนดการรายวัน รายสัปดาห์ นับถอยหลัง หรือเมื่อไม่ได้ใช้งาน
ปลุกพีซีจากโหมดสลีปหรือไฮเบอร์เนตด้วยตัวจับเวลา
ใช้ 0 MB เมื่อปิดแอป: ตัวจัดกำหนดการงานของ Windows เป็นผู้ทำงาน แม้หลังเริ่มระบบใหม่
ประมาณ 0.1 MB เมื่อมีไอคอนในถาด และ 2.3 MB เมื่อเปิดหน้าต่าง
หน้าตาเหมือนการตั้งค่าของ Windows พร้อมไอคอนสีเต็มและธีมสว่างและมืด
การแจ้งเตือน 1 นาทีพร้อมปุ่มทำงานทันที เลื่อน 10 นาที และหยุด
รองรับคีย์บอร์ด ผู้บรรยาย และ DPI ต่อจอภาพ
35 ภาษาพร้อมตัวเลือกภาษา
ฟรีและโอเพนซอร์ส (GPL-3.0)
